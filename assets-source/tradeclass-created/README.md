# tradeclass-created

PNGs gerados proceduralmente para a aba **Create** do TinyTraderLab.

Regenerar:

```bash
node scripts/iso-validation/gerar-created-assets.mjs
```

Catalogo: `scripts/iso-validation/created-assets.json` (`fileName` com prefixo `created/`).

Assets atuais: mesa branca, mesa metal, tapete branco, camera de filmagem, camera de cinema, suporte camera.
